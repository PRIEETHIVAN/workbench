🔌 Embedded Hardware Interface
Device discovery, connection management, and telemetry for MCU / FPGA / JTAG targets

⚠ Safety Notice — Read Before Connecting

  • Verify target board power supply voltage before connecting (3.3 V or 5 V — do NOT mix).
  • Never connect/disconnect JTAG while the target is powered in reset-protected state.
  • Ensure UART baud rate matches firmware configuration to avoid data corruption.
  • SPI clock polarity/phase (CPOL/CPHA) must match the FPGA bitstream — check datasheet.
  • Disconnect all devices before flashing new firmware to the FPGA.
